 // 感染者行为模式控制器
 // 
 // 1. 条目（控制器）属性：
 //    - 激活方式：蓝灯（constant / 永久激活）
 //    - 顺序：100
 //    - 插入位置：@角色定义前
 //    - 勾选：不可递归 + 防止进一步递归
 //
 // 2. 读取变量：
 //    - stat_data.世界阶段（秩序期 / 爆发期 / 末世期）

 //
 // 3. 条目加载逻辑：
 //
 //    注意：基础3条为全时期启用，秩序期也会加载
 //
 //    狂病型（全时期基础3条）：
 //      - 世界观-COVID-30感染者行为总纲
 //      - 杂项-合理性审查
 //      - 杂项-场景强化(可选)
 //
//    狂病型 + 爆发期（追加2条）：
//      - 世界观-爆发期
//      - 机制-动态威胁与安逸惩罚
//
//    狂病型 + 末世期（追加1条）：
//      - 机制-动态威胁与安逸惩罚
//
//    狂病型 + 末世期（再追加1条）：
//      - 杂项-感染者遭遇动态生成
 //
 //    普通型（全时期基础3条）：
 //      - 普通丧尸COVID-30感染者
 //      - 普通审查
 //      - 普通场景强化(可选)
 //

//      - 普通的动态威胁与安逸惩罚
//
//    普通型 + 末世期（追加1条）：
//      - 普通感染者遭遇
 //
// 4. 与世界阶段控制器的关系：
//    - 世界阶段控制器负责加载通用世界观/机制条目
//    - 本控制器负责加载感染者行为模式相关条目（已从世界阶段控制器移除，由本控制器接管）
//    - 世界观-爆发期 仅在爆发期加载（末世期由世界阶段控制器加载世界观-末世期）
//    - 机制-动态威胁与安逸惩罚 在爆发期和末世期均加载
}

1. 控制器条目配置：
   - 触发方式：蓝灯（constant，永久激活）
   - 顺序：100
   - 位置：@角色定义前
   - 勾选：不可递归 + 防止进一步递归

2. 各模式子条目配置：
   - 触发方式：全部设为禁用（disable）
   - 由控制器通过 getwi 按需加载，不需要自行触发
   - 顺序：98~800 即可

3. 条目加载矩阵：
   ┌─────────────┬──────────────────────────────────┬──────────────────────────────────┐
   │             │ 狂病型条目名                     │ 普通型条目名                     │
   ├─────────────┼──────────────────────────────────┼──────────────────────────────────┤
   │ 基础(全时期) │ 世界观-COVID-30感染者行为总纲     │ 普通丧尸COVID-30感染者           │
   │             │ 杂项-合理性审查                   │ 普通审查                         │
   │             │ 杂项-场景强化(可选)               │ 普通场景强化(可选)               │
   ├─────────────┼──────────────────────────────────┼──────────────────────────────────┤
   │ 爆发期专属  │ 世界观-爆发期                    │ 普通爆发期                       │
   ├─────────────┼──────────────────────────────────┼──────────────────────────────────┤
   │ 爆发期/末世期│ 机制-动态威胁与安逸惩罚          │ 普通-机制-丧尸尸潮               │
   │             │                                  │ 普通感染者多样性                 │
   │             │                                  │ 普通的动态威胁与安逸惩罚         │
   ├─────────────┼──────────────────────────────────┼──────────────────────────────────┤
   │ 末世期追加  │ 杂项-感染者遭遇动态生成           │ 普通感染者遭遇                   │
   └─────────────┴──────────────────────────────────┴──────────────────────────────────┘

4. 注意事项：
   - 子条目名称必须与 getwi() 中的字符串完全一致（含括号、标点）
   - 普通型条目名已无"/普通"后缀，使用独立命名避免 getwi 子串匹配误命中
   - 新增模式条目时，在对应 if 分支内添加 getwi 即可
